## About

This repo is my running log while working through **MIT 6.100L / 6.0001 — Introduction to Computer Science and Programming in Python**, alongside self-driven practice in data structures, OOP, and NumPy/Pandas. It's organized into four parts: course notes, standalone practice problems, small projects, and library-specific notebooks.

## 📘 MIT 6.100L Course Notes

Annotated code from following along with the course, one topic per file:

| File | Topic |
|---|---|
| `1.Python_basics.py` | Variables, printing, string concatenation & repetition |
| `2.AbstractionAndDecomposition.py` | Functions, decomposition, abstraction |
| `3.bisection_search.py` | Square-root approximation: incremental guessing vs. bisection search |
| `4.Tuples.py` | Tuple creation, indexing, slicing, immutability |
| `5.Lists.py` | List indexing, mutation, iteration, aliasing vs. cloning |
| `6.DefaultParameters.py` | Refactoring bisection search with default/explicit parameters |
| `7.HandlingExceptions.py` | `try`/`except`, input validation |

## 📊 Python Libraries

**NumPy — Basics** (`Python Libraries/Numpy/1.Basic NumPy/`)
Six notebooks covering array creation (1D/2D/3D, `dtype`, `arange`, `reshape`), array attributes (`ndim`, `shape`, `size`, `itemsize`), element-wise operations & comparisons, aggregate functions (`max`, `min`, `sum`, `mean`, `median`, `std`, row/column-wise), indexing & slicing, and iteration (`nditer`).

**NumPy — Advanced** (`Python Libraries/Numpy/2.Advance Numpy/`)
One notebook benchmarking vectorized NumPy operations against pure-Python loops on 10M-element arrays — the kind of hands-on comparison that shows *why* NumPy is fast, not just that it is.

**Pandas** (`Python Libraries/Pandas/College/`)
Just getting started here — `pandas.ipynb` currently has the import set up, ready to build on.
